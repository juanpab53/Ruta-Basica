# Ruta Básica — Riwi

A learning repository containing exercises, coding practices, and projects developed throughout the **Riwi Ruta Básica**.

This repository documents my learning journey in programming and web development, from the fundamentals of computational logic to building websites and small applications.

## Repository Structure

The repository is organized into different folders, each dedicated to a specific learning area:

| Folder | Description |
|---|---|
| `Algoritmos/` | Exercises focused on programming logic, problem-solving, and algorithmic fundamentals. |
| `IA/` | Activities and exercises related to Artificial Intelligence. |
| `PracticasHtml/` | HTML exercises focused on website structure and web development fundamentals. |
| `PracticasJavaScript/` | JavaScript exercises covering fundamental concepts. |
| `rueda-libre/` | Workspace dedicated to the Rueda Libre project. |

Additionally, the repository root contains an `index.html` file used as an entry point for one of the web development exercises.

## Technologies & Tools

- **HTML5:** Website structure and content.
- **CSS3:** Styling and visual presentation.
- **JavaScript:** Programming logic and interactivity.
- **Git & GitHub:** Version control and code management.
- **Artificial Intelligence Tools:** Exploration and practical application of AI concepts.

## Getting Started

You can explore the repository directly on GitHub or clone it to your local machine.

1. Clone the repository:

   ```bash
   git clone https://github.com/juanpab53/Ruta-Basica.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Ruta-Basica
   ```

3. Open the project using your code editor.

4. Explore the folders to access the different exercises and projects.

To preview the web development exercises, simply open their respective `index.html` files in your browser.
