## Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your system to run the files from your terminal.

---

## How to Run the Exercises

All exercises are intended to be executed locally via the command line.

1. Open your terminal in the root folder.
2. Run the desired solution file using **Node.js**:

```bash
node [file_name].js
```

### Example:

```bash
node nivelBajo.js
```

> **Note:** Please refer to the corresponding `.pdf` in the `documentation/` folder to understand the requirements and expected inputs before executing each script.
